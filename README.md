# ESPN Cricket Data Analysis
📊 Project Overview

ESPN Cricket Data Analysis is a Power BI dashboard created to practice data cleaning, transformation, and visualization using ODI cricket statistics sourced from ESPNcricinfo.

The project focuses on analyzing India vs South Africa ODI performance across three key areas: Batting, Bowling, and Fielding.

🎯 Objective

The main objective of this project was to practice Power BI by transforming cricket statistics into an interactive and easy-to-understand dashboard.

🔄 Data Preparation

The cricket data was collected from ESPNcricinfo's Statsguru and prepared for analysis in Power BI.

The data preparation process included:

Changing data types
Merging data
Appending datasets
Replacing values
Cleaning the data for dashboard use
📊 Interactivity

The dashboard includes player slicers that allow users to select individual players and view their corresponding batting, bowling, and fielding statistics.
